Choose how an external system talks to INPROFIC.

Headless API

Your own bakery/restaurant website directly reads INPROFIC's catalogue and submits orders to INPROFIC using the generated API key. Best for a website you control.

Platform webhook / connector

A third-party platform or adapter (for example WooCommerce/Shopify middleware) pushes normalized order events into INPROFIC. Requests are signed with the generated webhook secret.
