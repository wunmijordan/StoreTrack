Material category controls how this item is used: ingredients belong in recipes; packaging and production supplies (such as baking gas) can be attached to a product's production inputs; operational supplies (gloves, head nets, cleaning items) remain inventory/procurement items but are not consumed automatically by production.

Three layers, if you need them: what you buy → what's in the pack → what a recipe actually uses.

Purchase unit — bag, carton, pack. Package qty/unit — what's printed on it, e.g. 1 bag = 50 kg. Usage unit — the fine unit a recipe consumes: kg, g, spoon, cap.

Usage conversion — how many usage units in ONE package unit. Standard conversions: kg→g and litre→ml are both 1000. Same unit both ways (e.g. flour bought and used in kg) → 1. Non-standard units like spoon or cap aren't a fixed ratio — count it yourself (e.g. "1kg of ack fills 200 spoons" → usage unit spoon, usage conversion 200).

Stock and cost below are entered per purchase unit (e.g. "3" bags, "9000" per bag) — everything converts and stores internally in the fine usage unit, since that's what recipes and production deductions run on. Reorder level is entered in purchase units (e.g. "2" bags), but is converted and stored internally in the usage unit so existing stock calculations remain unchanged.
